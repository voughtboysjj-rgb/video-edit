# گزارش تحویل نسخهٔ حداقلی

## A. وضعیت کلی
ناقص. دو فایل MP4 واقعی با تصویر و صوت ساخته‌شده توسط پروژه تولید شد. کیفیت/محتوا معادل فیلم مرجع نیست. هیچ آپلود یوتیوبی صورت نگرفته است.

## B. تغییرات
CLI در `src/shorts_automation/cli.py`، تست‌های `tests/test_core.py`، قفل Pillow، تنظیمات طرح/مراجع/LLM، گزارش تحلیل مرجع، دو MP4 و گزارش JSON آن‌ها، README و مستندات واقعی اضافه شدند. workflow برای تست و رندر دستی تعریف شد. ماژول‌های ASR، API، analytics و workflow انتشار عمداً ایجاد نشدند چون پیاده‌سازی واقعی ندارند.

## C. تست
فرمان: `PYTHONPATH=src python -m unittest discover -s tests -v`
ده تست محلی passed، صفر failed. تست‌ها شامل اعتبارسنجی طرح/حقوق/ابعاد، تغییر هش، قطعی‌بودن فریم و تفاوت واریانت‌ها و ساخت صوت واقعی و FFprobe هستند. اتصال خارجی Mock یا زنده در این مجموعه وجود ندارد. این ده تست، پوشش همهٔ معیارهای پرامپت نیست.

## D. مسیر واقعی
مولد هندسی داخلی و سینت سایزر برنامه‌ای، بدون تصویر یا موسیقی مرجع. خروجی‌ها 16 ثانیه، 1080×1920، 24fps، H.264/AAC هستند. تصویر ابتدا 540×960 تولید و بزرگ شده است. FFprobe و decode کامل اجرا شدند. نتایج QC و hash در JSON همراه هر فایل است. خوانایی، زیبایی، crop معنایی، clipping و loudness یکپارچه به‌طور کامل اعتبارسنجی نشده‌اند.

## E. سرویس‌ها
YouTube Data/Analytics/OAuth: not_configured و not_implemented. FreeLLM: صفحه مرور شده، API متصل نیست. در این نسخه هیچ Secret لازم نیست. مرحلهٔ آینده به OAuth client و token مجاز کانال نیاز دارد؛ جزئیات scope و سیاست باید هنگام پیاده‌سازی از اسناد رسمی بررسی شود. هرگز توکن را در ریپو قرار ندهید.

## F. اجرا
فرمان‌های نصب، environment، plan، produce و qc در README موجود و واقعی‌اند. برای upload/publish/analytics فرمانی وجود ندارد. اجرای مجدد produce با هش سالم از رندر دوباره جلوگیری می‌کند.

## G. گام‌های بعدی
1. بررسی انسانی دو خروجی؛ این‌ها صرفاً اثبات pipeline هستند و دو ایدهٔ مستقل سینمایی محسوب نمی‌شوند.
2. بانک منابع مجاز و انتخاب لحظه/تدوین کلیپ واقعی.
3. تحلیل دقیق صدا و کات مرجع؛ detector فعلی فقط تغییرات تصویر را علامت می‌زند.
4. تکمیل QC، مدل تأیید معتبر و state machine پیش از OAuth و upload.
5. ذخیره‌سازی پایدار بین اجراها پیش از Cron. تولید دو خروجی تازهٔ روزانه هنوز پیاده نشده است.
