# The Switch — تدوین تازه
این نسخه برخلاف بازچینی قبلی، یک تایم‌لاین تازه با ۱۶ قطعه است. شروع با نمای جدی، بازگشت کوتاه به طنز، سپس تغییر در ثانیهٔ ۳ و مونتاژ اکشن. مدت ۱۴ ثانیه، ۴۲۰ فریم، 1080×1920 و 30fps.

## کارهای تألیفی این نسخه
- انتخاب ترتیب و مدت قطعات، با کات‌ها روی شبکهٔ نیم‌ثانیه‌ای.
- تغییر سرعت مستقل هر قطعه بین 0.7x تا 1.4x؛ این تغییرات پیوستهٔ Speed Ramp نیستند.
- مقیاس متحرک foreground کامل درون قاب عمودی، بدون حذف عمدی نوشته‌ها.
- رنگ‌بندی کم‌اشباع‌تر بخش طنز در مقابل کنتراست و اشباع بیشتر مونتاژ.
- متن‌های جدید در حاشیهٔ خارج از تصویر اصلی و خط گرافیکی قرمز.
- موسیقی کاملاً جدید سینتزشده با seed ثابت، درام، بیس و آرپژ. تمپو 120BPM بر مبنای کلاک آهنگسازی است، نه تخمین موسیقی مرجع. در ثانیهٔ ۳ درام قوی‌تر می‌شود.
- پایان با Fade مستقل.

## کارهای متعلق به منبع
تمام شخصیت‌ها و تصویر فیلم، نوشتهٔ HOBO و افکت‌های پخته‌شده در تصویر از منبع می‌آیند. ادعای ساخت انیمیشن فیلم یا بازیابی لایه‌های اصلی نداریم. حقوق بر اساس اظهار کاربر ثبت شده، نه بررسی مستقل.

## شواهد
خروجی: `outputs/fresh_edit_the_switch.mp4`
تایم‌لاین و گزارش: `outputs/fresh_edit_the_switch.json`
بررسی‌های واقعی: `reports/fresh_edit_checks.json`
ابعاد، تعداد فریم، مدت، اختلاف مدت صوت/تصویر و Decode کامل موفق بودند. مسیر صوتی خروجی با مرجع متفاوت است. نمونه‌فریم‌ها بصری مرور شدند؛ شنیدن انسانی کامل انجام نشده است. زیبایی یا پذیرش پلتفرم را تضمین نمی‌کنیم.

## بازتولید
```bash
python -m pip install -r requirements.lock
# FFmpeg/FFprobe و fonts-dejavu-core باید نصب باشند.
python create_fresh_edit.py
```
این نسخه اسکریپت ثابت برای همین فایل است، نه موتور عمومی تدوین روزانه. فایل نهایی پس از QC از مسیر موقت منتقل می‌شود. انتشار یوتیوب انجام نشده است.
