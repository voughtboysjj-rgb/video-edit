# مهندسی معکوس مرجع — تحویل مرحلهٔ تحلیل

## وضعیت
**ناقص: تحلیل اندازه‌گیری‌شده و بازچینی تایم‌لاین اجرا شده، بازیابی مستقل افکت‌ها انجام نشده است.**
دو فایل جدید با ادیت خلاقانه تحویل نشده؛ این مرحله شواهد و ابزار بازسازی تایم‌لاین است.

## یافته‌های واقعی
- 1246 فریم ویدیویی؛ 1080×1200، 60fps. مدت تصویر 20.7667 ثانیه؛ مدت کانتینر/صدا اندکی بیشتر است.
- امتیاز تغییر صحنهٔ FFmpeg برای هر فریم پس از کاهش عرض به 270 محاسبه شد. آستانهٔ 0.12 و گروه‌بندی رخدادهای نزدیک، نامزدهای مرز را می‌سازند؛ این detector ممکن است فلاش و حرکت را با کات اشتباه بگیرد و دیزالوها را از دست بدهد.
- تغییر شخصیت/فضا حوالی 10.2 ثانیه از Contact Sheet دیده شد. مرز 610/60 صرفاً تخمین تصویری است، نه مرز قطعی.
- تایم‌لاین به 13 بلوک نامزد تقسیم شد. بعضی بلوک‌ها چند شات دارند؛ «13 کات تأییدشده» ادعا نمی‌شود.
- حدود 0 تا 10.2 ثانیه بخش معرفی طنز، سپس تغییر به مونتاژ شخصیت جدی؛ حوالی 14 تا 16.5 تنوع سریع‌تری از تصاویر و رنگ‌ها دیده می‌شود؛ پایان به زمینهٔ سیاه با نوشته می‌رسد. این توصیف مشاهده‌ای است، نه اثبات منحنی افکت.
- RMS صوت در پنجره‌های 20ms و جهش‌های انرژی اندازه‌گیری شد. جهش انرژی معادل Beat نیست؛ BPM برابر null مانده است.

## خروجی‌ها
- `outputs/reconstruction_breakdown.mp4`: ویدیو با برچسب تحلیل بلوک‌ها؛ نوشتهٔ اضافه‌شده مربوط به گزارش است، نه بازسازی ظاهر مرجع.
- `outputs/reconstructed_timeline.mp4`: تقسیم و بازچینی همان پیکسل‌های ورودی با تعداد فریم برابر. بدون افکت تازه، بدون تغییر نسبت تصویر؛ صدای موجود stream-copy شده است.
- `reports/reconstruction/edit_plan.json`: بازه‌های دقیق فریمی، امتیازهای صحنه، وضعیت بازیابی و مشخصات خروجی.
- `reports/reconstruction/audio_energy.json`: اندازه‌گیری انرژی و رخدادهای احتمالی، بدون ادعای BPM.
- `reports/reconstruction/timeline_sheet.jpg`: نمونه‌های هر 0.25 ثانیه از ثانیهٔ 9 به بعد. برچسب‌ها زمان نسبی به‌اضافهٔ 9 ثانیه‌اند؛ زمان‌ها به دقت نمونه‌برداری محدودند.
- `reports/reconstruction/measurements.png`: نمودار اندازه‌گیری تصویر و صوت.

## مقایسه و آزمون واقعی
SSIM کلی پس از بازکدگذاری: **0.961765**. این مقدار، شاخص بازیابی افکت نیست؛ فقط اختلاف پیکسل‌های بازچینی/بازکدگذاری‌شده را می‌سنجد. این بازکدگذاری افت کیفیت دارد و جایگزین آرشیوی فایل اصلی نیست.
تعداد فریم بازچینی‌شده: **1246**؛ تطبیق موفق. Decode کامل FFmpeg بدون خطای گزارش‌شده انجام شد. هش محتوای صوتی اصلی و کپی‌شده با `ffmpeg -f hash` یکسان بود.

فرمان تست: `PYTHONPATH=src python -m unittest discover -s tests -v`
نتیجهٔ محلی: 16 موفق، صفر ناموفق. شش تست جدید عمدتاً اعتبار مصنوعات/گزارش واقعی و پوشش تایم‌لاین را بررسی می‌کنند؛ اجرای مستقل encoder در هر تست انجام نمی‌شود. شواهد اجرای encoder در اجرای اصلی pipeline است.

## چه چیزهایی بازیابی نشده
سکانس قبل از کراپ، فریم‌های حذف‌شده، لایهٔ بدون نوشته، منحنی زوم/سرعت، LUT و لایه‌های ترنزیشن، صدای موسیقی مجزا و گفتار جداگانه. هر کدام هنوز `not recovered` است. استفاده از افکتِ پخته‌شده داخل تصویر، بازسازی آن افکت از صفر نیست.

## اجرای مجدد
```bash
python -m pip install -r requirements.lock
# FFmpeg و FFprobe و فونت DejaVu باید نصب باشند.
python reverse_engineer.py
PYTHONPATH=src python -m unittest discover -s tests -v
```
این اسکریپت فقط روی مسیر ثابت فایل مرجع محلی کار می‌کند. CLI عمومی تحلیل هر فایل، پروفایل افکت قابل تعمیم و تولید خودکار روزانه هنوز وجود ندارند. رندر به‌صورت مستقیم نوشته می‌شود؛ قطع اجرا می‌تواند خروجی نیمه‌تمام باقی بگذارد و باید اجرای بعدی آن را جایگزین کند. این محدودیت با رندر اتمیک pipeline اورجینال متفاوت است.

## گام منطقی بعدی
بازبینی فریم‌های اطراف نامزدها و اندازه‌گیری تغییر اندازه/مکان سوژه با جداسازی حرکت دوربین از حرکت انیمیشن. بدون سکانس خام، بازسازی مستقل بعضی افکت‌ها فقط تخمین خواهد بود. سامانهٔ انتشار در این مرحله فعال نیست.
