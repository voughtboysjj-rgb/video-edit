# معماری نسخهٔ 0.1
ورودی تولیدی این نسخه فقط مولد داخلی محتوای هندسی است. فایل مرجع به مولد داده نمی‌شود.

`plan_for → validate → procedural frames + score → FFmpeg → QC → atomic rename → report + SQLite`

رندرها تک‌پردازشی‌اند؛ SQLite صرفاً وضعیت رندر را ثبت می‌کند و ماشین حالت انتشار نیست. `awaiting_review` معادل تأیید انتشار نیست. هیچ کد آپلود یا عمومی‌سازی وجود ندارد.

تصمیم کاهش دامنه: ایجاد ده‌ها ماژول خالی کنار گذاشته شد. یک CLI واقعی با چهار فرمان به‌جای رابط فرضی ارائه شد. طرح در JSON ذخیره شده (زیرمجموعهٔ YAML). پروفایل‌های پیشنهادی گسترده هنوز وجود ندارند.

محدودیت‌ها: مدت و ابعاد فعلاً ثابت‌اند؛ فایل فونت مسیر Linux دارد. timeout برای subprocessهای بررسی و انتظار پایان encoder هست، اما timeout سراسری برای کل تولید وجود ندارد. پایداری SQLite بین Runnerها پیاده نشده است. بازتولید محتوا با seed ممکن است ولی هش باینری بین نسخه‌های encoder تضمین نمی‌شود. Retry خودکار و انتشار شبکه‌ای نداریم.
