# نسخهٔ ۲۰ثانیه‌ای — Director’s Cut

## تغییرهای تدوینی نسبت به نسخهٔ قبلی
- قاب عمودی تمام‌صفحه با focal point هر قطعه، بدون پس‌زمینهٔ محو؛ در نتیجه بخشی از کناره‌های تصویر اصلی خارج از قاب است. نوشته‌ها به‌صورت انتخابی پاک/ماسک نشده‌اند؛ نوشتهٔ HOBO در نماهای مرکزی منبع وجود دارد. اعتبار منبع: ویدیوی ارائه‌شده توسط کاربر، با اظهار مجازبودن تصاویر و موسیقی؛ بررسی مستقل انجام نشده.
- ۵ ثانیه آغاز طنز و سپس تغییر فضا روی Drop.
- ۲۶ قطعه با زمان‌بندی فریم‌محور؛ نقاط برش روی شبکهٔ ۱۴۴ BPM، هر ضرب ۲۵ فریم در ۶۰fps.
- variation میان نمای معرفی، نمای قهرمان، واکنش، جزئیات، کات کوتاه و مکث. برخی قطعات از بخش‌های متفاوت همان منبع تکرار می‌شوند؛ فیلم خام تازه نداریم.
- تغییر سرعت مستقل، focal crop، لرزش کوتاه و کاهنده در لحظهٔ ضرب و chromatic offset بسیار کوتاه روی قطعات impact. زوم متحرک پیوسته یا speed ramp پیوسته ادعا نمی‌شود.
- حذف متن‌های تکراری و خط تزئینی؛ فقط WAIT کوتاه پیش از تغییر فضا.
- موسیقی کاملاً تازهٔ ساخته‌شده با کد: کاوبل فلزی، بیس اشباع‌شدهٔ 808-style با glide، kick، snare، hi-hat، riser و downlifter؛ هیچ سمپل شخص ثالث یا موسیقی مرجع در خروجی استفاده نشده است.

## شواهد فنی
۲۰٫۰۰۰ ثانیه؛ ۱۲۰۰ فریم؛ نرخ متوسط 60/1؛ ۱۰۸۰×۱۹۲۰؛ H.264/AAC. Decode کامل و تطابق مدت صدا و تصویر موفق. شش بررسی فنی فایل و شش بررسی طرح اجرا شدند؛ این‌ها ممیزی کامل پروژه نیستند.
میانگین sample volume: ‎−۱۷٫۵ dBFS؛ sample peak: ‎−۳ dBFS. سنجش loudnorm روی ورودی: ‎−۱۷٫۲۳ LUFS و true peak برابر ‎−۲٫۷۱ dBTP؛ این سنجش صرفاً اندازه‌گیری است، نه اجرای normalization.
دو رندر اولیه به‌دلیل اختلاف timing/fps رد شدند؛ نسخهٔ تحویلی خروجی CFR اصلاح‌شده است. نمونه‌فریم‌ها مرور شدند، اما شنیدن انسانی حرفه‌ای و ارزیابی مستقل جذابیت انجام نشده است.

## محدودیت و مرز تألیف
همهٔ تصاویر شخصیت‌ها و افکت‌های پخته‌شده از منبع می‌آیند؛ ترتیب، مدت، افکت‌های جدید و score تألیف پروژه‌اند. crop و upscale جزئیات واقعی تازه ایجاد نمی‌کنند. در بخش آهسته، بعضی فریم‌ها تکرار می‌شوند؛ optical flow اعمال نشده. این فایل ادعای برتری اثبات‌شده نسبت به مرجع ندارد؛ مقایسهٔ زیبایی‌شناختی با کاربر است.

## بازتولید
```bash
python -m pip install -r requirements.lock
python create_phonk_directors_cut.py
```
نیازمند FFmpeg/FFprobe با libx264، drawtext و rgbashift و فونت DejaVu. فایل مرجع باید در ریشهٔ پروژه باشد. فایل‌های میانی پس از موفقیت پاک می‌شوند؛ پس از خطا برای بررسی باقی می‌مانند. هیچ آپلودی به یوتیوب انجام نشده است.
